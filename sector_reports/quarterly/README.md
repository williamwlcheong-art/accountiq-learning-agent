# AccountIQ quarterly market intelligence

This directory contains versioned New Zealand macroeconomic and sector-scale
snapshots used by valuation and bank credit reports.

- `index.json` identifies the current snapshot.
- Snapshot files are immutable after publication. Corrections create a new
  snapshot and update the index rather than silently rewriting a report basis.
- Numeric measures use primary official sources and retain their period, unit,
  source identifier, method and limitations.
- Private-industry measures are described as **sector turnover/scale proxies**,
  not market capitalisation. They are not an estimate of listed-equity value,
  enterprise value or a subject company's addressable market.
- The normal review cadence is quarterly, after the March, June, September and
  December source releases are available.
